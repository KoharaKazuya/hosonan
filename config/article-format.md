# 記事フォーマット設定

この記事生成システムは、次の記事形式を基本に記事を作成します。実際の運用に合わせて、このファイルを編集してください。

`PROMPT.md` に書かれているシステム上必須の出力形式、`slug` ルール、出典追跡ルールは常に優先します。

## 文体

- 日本語で書く
- ですます調を基本にする
- 簡潔で、事実関係を追いやすい文章にする
- 専門用語は必要に応じて短く補足する
- 主観的な評価は、事実と区別して書く

## 記事構成

次の Markdown 形式を基本にします。

```markdown
---
title: 記事タイトル
slug: topic-slug
createdAt: YYYY-MM-DDTHH:mm:ss+HH:MM
updatedAt: YYYY-MM-DDTHH:mm:ss+HH:MM
---

# 記事タイトル

## 要約

- 重要ポイント 1。[^1]
- 重要ポイント 2。[^2]
- 未確定または今後確認すべき点。

## 発表・更新された内容

本文をここに記載します。重要な事実、日付、数値、固有名詞には、対応する Footnote 記法の出典 ID を付けます。[^1]

## これまでの経緯

この発表や更新に至る経緯をここに記載します。

## 利用者や開発者に変わること

利用者、開発者、企業、サービス運用などに関係する具体的な変化をここに記載します。

## 次に確認すべき時期と対象

今後確認すべき時期、対象、公開予定、未確定事項をここに記載します。

---

<details>
<summary>確認できていること</summary>

| 事実 | 根拠 |
| --- | --- |
| 確認した事実 | [^1] |

</details>

<details>
<summary>未確認・留意点</summary>

- 現時点で確認できない点、出典間で差分がある点、今後更新される可能性がある点。

</details>

[^1]: サイト名, [ページタイトル](URL)
[^2]: サイト名, [ページタイトル](URL)
```

## タイトル

- 本文で確認できる事実の範囲内で書く
- 読者が記事の主題をすぐ理解できる具体性を持たせる
- 速報性だけを強調しない

## 要約

- 3 点を目安にする
- 事実、読者に関係する変化、未確定事項の順に整理する
- 本文を読まなくても主要論点が把握できるようにする
- 重要な事実には Footnote 記法の出典 ID を付ける

## 本文の書き方

- 冒頭で、何が起きたのかを簡潔に説明する
- 「本文」という見出しは使わず、内容に応じた分かりやすい見出しで分割する
- 標準的には、出来事、経緯、読者や関係者にとっての変化、今後確認すべき点を順に整理する
- 実際の記事見出しでは、「背景」「影響」「今後の確認点」のような抽象的な語だけを使わず、そのセクションが主張している具体的な内容を表す
- 見出しは記事ごとに書き換える。例えば「影響」ではなく「有料プラン利用者は追加料金なしで利用できる」、「背景」ではなく「企業向け導入の拡大に合わせて管理機能を追加する」のように書く
- 複数の情報源で内容が異なる場合は、その差分を明記する
- 推測を書く場合は、推測であることを明示する
- 日付、数値、固有名詞、引用、重要な因果関係には Footnote 記法の出典 ID を付ける
- 本文の最後と、末尾の「確認できていること」「未確認・留意点」「脚注定義」の間には区切り線 `---` を置く

## 確認できていること

- 記事内の主要な事実と根拠の対応を表で示す
- 本文を読み返さなくても、どの出典で何を確認したか分かる粒度にする
- 普段の閲覧では目立たないように、`<details>` と `<summary>` で折りたたんで記載する

## 未確認・留意点

- 未確認情報、出典間の差分、今後更新される可能性がある点を短く書く
- 未確認事項がない場合は「現時点で大きな未確認事項は確認していません」と書く
- 普段の閲覧では目立たないように、`<details>` と `<summary>` で折りたたんで記載する

## 脚注定義

- 記事中で根拠にした出典のみを載せる
- 公式発表、一次情報、主要メディアの順に並べる
- リンク名は媒体名または文書名が分かる表記にする
- 脚注定義は `<サイト名>, <リンク化したページタイトル>` の形式で書く
- GitHub Footnote 記法として表示されるため、「根拠・参考リンク」の見出しは作らず、記事末尾に脚注定義を直接記載する
- 本文中に出てくる Footnote 出典 ID の脚注定義がすべて存在するようにする

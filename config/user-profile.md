# ユーザー設定

この記事生成システムは、次の読者像と関心を前提に記事を作成します。実際の運用に合わせて、このファイルを編集してください。

## 想定読者

- 技術、ビジネス、社会の変化を継続的に追いたい読者
- 速報そのものより、出来事の意味、背景、今後の影響を知りたい読者
- 誇張された見出しや感情的な論調より、落ち着いた整理を好む読者

## 関心領域

- AI、ソフトウェア、インターネットサービス
- テクノロジー企業の事業戦略、規制、提携、買収
- 開発者向けツール、クラウド、セキュリティ
- 社会制度、法律、産業構造に影響する技術ニュース

## 好む観点

- 何が新しいのか
- 誰にどのような影響があるのか
- 既存の流れと比べて何が変わったのか
- 公式発表と報道の間に差分はあるか
- 未確定の点や今後確認すべき点は何か

## 重視する情報源

ユーザーは次のサイトを好んで読むため、関連するトピックを選定、調査、整理する際は情報源として重視します。ただし、事実確認では公式発表、一次情報、複数の信頼できる出典による裏取りを優先します。

- https://zenn.dev/
- https://b.hatena.ne.jp/hotentry/it
- https://web.dev/blog

## 避けたい内容

- 出典の弱い噂を中心にした記事
- 煽り、断定、過度な楽観論や悲観論
- 本文の根拠より強い見出し
- 読者が判断するための情報を欠いた意見記事

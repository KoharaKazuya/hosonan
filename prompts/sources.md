# 情報源

## 基本方針

最新ニュースを扱う場合は、必ず Web 検索を使って現在の情報を確認します。古い知識だけで記事を書かないでください。

情報源は、信頼性と検証可能性を重視して選びます。速報性よりも、読者が記事 Markdown の中で根拠を確認できることを優先します。

## 優先順位

1. 公式発表、規制当局、裁判所、企業ブログ、決算資料、プレスリリース
2. 当事者の一次発言、登壇資料、公開された書簡、公式 SNS
3. 主要メディア、専門メディア、通信社
4. 複数の独立した媒体で確認できる二次情報

## 採用しない情報

- 出典が確認できない投稿
- 匿名情報だけに依存した内容
- 一次情報や主要メディアで確認できない噂
- 広告、アフィリエイト、宣伝目的が強いページ
- 生成 AI による要約ページなど、元情報にたどれないページ

## 検証ルール

- 重要な事実は、可能な限り 2 つ以上の独立した出典で確認する
- 公式情報と報道が食い違う場合は、公式情報を基準にし、差分を本文で説明する
- 日付、数値、固有名詞、肩書き、引用は出典と照合する
- 法律、医療、金融、災害、安全保障に関する記事では、公式情報を必ず確認する
- 確認できない情報は本文に採用せず、必要なら「現時点では確認できない」と書く

## 記事内での根拠管理

出典情報は、記事とは別の JSON ではなく、最終出力の Markdown 記事内に含めます。読者が記事ファイルだけを読んで、本文の主張と根拠の対応を確認できるようにしてください。

- 本文中の重要な事実には `[S1]` のような出典 ID を付ける
- 記事末尾に「根拠・参考リンク」を置き、出典 ID ごとに出典名、公開日、取得日時、URL、確認した内容を書く
- 記事中の主要な事実は「確認できていること」にまとめ、根拠 ID と対応させる
- 出典 ID は記事ごとに `S1` から採番し、別記事と共有しない
- 同じ出典を複数の記事で使う場合も、各記事の「根拠・参考リンク」に必要な情報を個別に記載する

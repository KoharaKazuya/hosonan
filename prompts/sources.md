# 情報源

## 基本方針

最新ニュースを扱う場合は、必ず Web 検索を使って現在の情報を確認します。古い知識だけで記事を書かないでください。

情報源は、信頼性と検証可能性を重視して選びます。速報性よりも、読者が根拠を確認できることを優先します。

## 優先順位

1. 公式発表、規制当局、裁判所、企業ブログ、決算資料、プレスリリース
2. 当事者の一次発言、登壇資料、公開された書簡、公式 SNS
3. 主要メディア、専門メディア、通信社
4. 複数の独立した媒体で確認できる二次情報

## 採用しない情報

- 出典が確認できない投稿
- 匿名情報だけに依存した内容
- 一次情報や主要メディアで確認できない噂
- 広告、アフィリエイト、宣伝目的が強いページ
- 生成 AI による要約ページなど、元情報にたどれないページ

## 検証ルール

- 重要な事実は、可能な限り 2 つ以上の独立した出典で確認する
- 公式情報と報道が食い違う場合は、公式情報を基準にし、差分を本文で説明する
- 日付、数値、固有名詞、肩書き、引用は出典と照合する
- 法律、医療、金融、災害、安全保障に関する記事では、公式情報を必ず確認する
- 確認できない情報は本文に採用せず、必要なら「現時点では確認できない」と書く

## 出典メタデータ

記事とは別に出典情報を保存する場合は、次の JSON 形式を基本にします。

```json
{
  "topic": "キーワード",
  "generated_at": "YYYY-MM-DDTHH:mm:ss+09:00",
  "sources": [
    {
      "title": "出典タイトル",
      "url": "https://example.com",
      "publisher": "媒体名",
      "published_at": "YYYY-MM-DD",
      "accessed_at": "YYYY-MM-DDTHH:mm:ss+09:00",
      "source_type": "official | primary | media | secondary",
      "used_for": ["事実確認", "背景説明"]
    }
  ]
}
```
